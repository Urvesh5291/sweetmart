# Patel Sweet Mart 🍬

આ વેબસાઇટ **પટેલ સ્વીટ માર્ટ** (ખેરવા • અમદાવાદ) માટે બનાવવામાં આવી છે, જે પરંપરાગત ગુજરાતી મીઠાઈ, નમકીન અને ગિફ્ટ હેમ્પર્સ પ્રદર્શિત કરે છે.

## સુવિધાઓ (Features)
- 100% રિસ્પોન્સિવ અને મોર્ડન ગુજરાતી થીમ ડિઝાઇન
- તમામ પ્રોડક્ટ્સ (મોહનથાળ, તોરાપાક, લાડવા, જલેબી વગેરે) માટે અલગ પੇજ
- સીધો WhatsApp ઓર્ડર બટન ఇంటిગ્રેશન
- 1995 થી ચાલી આવતી પરંપરાનો ઇતિહાસ

## ફાઇલોની રચના (File Structure)
- `index.html` - હોમપેજ
- `products.html` - બધી પ્રોડક્ટ્સની સૂચિ
- `style.css` - વેબસાઇટની ડિઝાઇન અને કલર કોડ
- તમામ પ્રોડક્ટ અને લોગો ઇમેજ ફાઇલો (જેવી કે `Patel Sweet Mart Logo.jpg`, `ladva.jpg`, વગેરે) એક જ ફોલ્ડરમાં રાખવી.
