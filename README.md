# Patel Sweet Mart Website 🍬

Official website for **Patel Sweet Mart** (ESTD. 1995), Kherva & Ahmedabad. 
Showcasing authentic Gujarati sweets, traditional namkeen, feni, mohanthal, and special festival gift hampers.

## Features
- Authentic warm cream background & royal borders matching brand identity.
- Full product catalog showcase using local image files.
- Direct WhatsApp Order integration.
- Fully responsive design for mobile and desktop.
